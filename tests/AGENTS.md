# Tests

`README.md` in this directory says which suite answers which question; each
suite's own README carries its conventions and the rules for its thresholds
and baselines. Read both before adding or changing a test.

The simulation-running suites write to fixed paths under their deck
directories, so run one such suite at a time per checkout.
