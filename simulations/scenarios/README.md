# Reference scenarios

This folder contains the four scenarios shipped with Navigate. These four scenarios serve as placeholders for model
testing with various degrees of regulatory stringency. However, these scenarios do not represent the Center's view on
likely future decarbonization scenarios or expectations on future regulation.

## Runtime

A full scenario run takes roughly 25 minutes on the bundled open-source HiGHS solver
(faster with a licensed Gurobi installation, see `--solver`). For a quicker first run, start
with the smaller decks in `simulations/examples/` or the tutorials.
