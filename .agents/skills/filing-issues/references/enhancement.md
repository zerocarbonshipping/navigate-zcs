# Filing an enhancement

- **Motivation** comes from the user's side: what a deck author cannot
  express today, or what a reader of the output cannot see, and why it
  matters for the modelled sector.
- **Proposed design** names the DSL surface affected: the attributes,
  commands, keywords and report properties added or changed, with the deck
  lines a user would write. It names the reference-manual pages that would
  change.
- **Alternatives** considered go in Proposed design too, each with the
  reason it was not chosen.
- New assumption values proposed with the feature come with references or a
  justification.
