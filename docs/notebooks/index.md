# Notebooks

Workshop sessions that run a case end to end in a Jupyter notebook, on Google
Colab or on your own machine. Each page shows the notebook with the results of
a run, so it can be read without running it.

```{toctree}
:titlesonly:

```

## Running a notebook on your own machine

Colab needs nothing installed and is recommended. To run a notebook locally instead, you need:

- The notebook `.ipynb` file.
- Python 3.13
- A fresh environment, `conda` or `venv`
- A Jupyter kernel in that environment: `pip install ipykernel`
- git
- `ROOT` set to a folder of your own
