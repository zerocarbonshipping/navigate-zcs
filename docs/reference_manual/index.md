# Reference Manual

Navigate is a node-based simulator: every entity in a simulation deck is a node
defined in the `.nav`/`.inc` DSL. This manual covers the DSL syntax and every
node type. Start with the introduction and the DSL reference, then consult
individual node pages as needed.
